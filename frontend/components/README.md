# Frontend UI Components

Reusable modular components rendered client-side by 'frontend/js/app.js' and 'frontend/js/admin.js':
- Navigation Bar (Desktop & Mobile)
- Footer with Temple Timings & Quick Links
- Bilingual Language Switcher (EN <-> KN)
- User Profile & Authentication Dropdown
- Document & Image Lightbox Modals
- Toast Notification System
